# TPerl MiniCE Bridge

WoW Forever addon that makes TPerl aura icons match MinimalistCooldownEdge (MiniCE).

- **Timer text**: TPerl's aura timers use MiniCE's Unit Frames font, size, outline and "Color by Remaining Time" threshold colors. Changing MiniCE settings rebuilds TPerl's aura icons so changes show right away.
- **Icon look**: TPerl aura icons get the Blizzard nameplate aura look (rounded mask, Cooldown Manager frame, rounded swipe) instead of TPerl's dispel-colored border.
- **Hidden buffs**: buffs listed in `HideBuffs.lua` (Find Minerals by default) are left off TPerl's player buff row.

Requires TPerl and MinimalistCooldownEdge.
